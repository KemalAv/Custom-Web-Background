# Custom Web Background

Tired of boring plain pages? This extension lets you add your own wallpaper behind every website you visit.

### Add Wallpapers to Any Website!

Make your browser look clean, modern, and personal. This extension seamlessly applies custom wallpapers behind website interfaces while keeping text, buttons, and inputs clear and legible.

### Key Features:
1. **Ultra Lightweight & Zero Lag:**
   - Pre-bakes blur and dimming directly onto canvas before rendering, eliminating real-time GPU filter lag and forced layout reflows.
   - Old oversized media is automatically cleaned up and optimized to prevent browser memory bloat.
2. **Comfortable Eye-Care Defaults:**
   - Comes out-of-the-box with **75% Dim** and **5px Blur** so text is instantly readable and comfortable for the eyes.
3. **Customizable Auto Dim Theme Colors:**
   - In **Auto** mode, independently customize the overlay colors for **Dark Theme** (default `#000000`) and **Light Theme** (default `#FFFFFF`) to fit your aesthetic.
4. **Universal Compatibility:**
   - Works seamlessly across all websites, including Google, YouTube, Reddit, and social media.
5. **Universal Media Support:**
   - Upload custom JPG, PNG, GIF, or MP4 video backgrounds or enter media URLs.
6. **Fluid UI Animations & Glass UI:**
   - Enjoy subtle glassmorphism and smooth, configurable interface animations.
