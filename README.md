Add Wallpapers to Any Website!

Make your browser look clean and modern. This extension lets you add custom wallpapers to any website you visit.

Features:
1. Custom Uploads: Upload your own wallpapers or choose from a link.
2. Universal Compatibility: Works seamlessly across all websites, including Google, YouTube, and Reddit.
3. Adjustable Blurs: Customize the dimming and blur effects to create your perfect look.
4. UI Animations: Enjoy fluid animations during user interface interactions.
