# Custom Web Background - Add Wallpaper to Any Websites

Tired of plain, boring white and dark pages? This extension lets you set custom image or video wallpapers behind every website you visit.

### Add Wallpapers to Any Website!

Make your browser look clean, modern, and personal. This extension seamlessly applies custom wallpapers behind website interfaces while keeping text, buttons, and inputs crisp and legible.

### Key Features:
1. **Ultra Lightweight & Zero Lag:**
   - Pre-bakes blur and dimming directly onto canvas before rendering, eliminating real-time GPU filter lag and forced layout reflows.
   - Automatically cleans up oversized media to prevent browser memory bloat.
2. **Comfortable Eye-Care Defaults:**
   - Comes out-of-the-box with **75% Dim** and **0px Blur** (with quick **5px Eye-Care** and **25px Deep Focus** presets) so text is instantly readable and comfortable for long browsing sessions.
   - Dynamic **Custom** preset badge reflects your real-time slider values (e.g., Blur: 0px • Dim: 60%).
3. **Flexible Target Websites:**
   - Choose **All Websites** or specify up to **10 Specific Websites** with convenient 1-click active website detection and easy domain management.
4. **Customizable Auto Dim Theme Colors:**
   - In **Auto** mode, independently customize the overlay colors for **Dark Theme** (default `#000000`) and **Light Theme** (default `#FFFFFF`) to fit your aesthetic.
5. **Universal Compatibility & Media Support:**
   - Works across all websites, including Google, YouTube, Reddit, and social media.
   - Upload custom JPG, PNG, GIF, or MP4 video backgrounds or enter media URLs.
6. **Fluid UI Animations & Glass UI:**
   - Enjoy subtle glassmorphism and smooth, configurable interface animations.
