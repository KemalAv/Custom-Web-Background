# Custom Web Background - Custom Wallpapers with Blur & Dim for Any Website

**Make every website aesthetic, personal, and yours.**
GlassUI lets you add **custom wallpapers** with **glassmorphism blur and dim overlays** on *any* website: Google, YouTube, Reddit, etc...

## Privacy

GlassUI **does not collect any personal data**.
We only use `storage` to save your local wallpaper, blur, and dim settings. So your vibe stays put!

**No remote code, no tracking.**


## Display Modes & Website Targeting

### 1. Transparent Display & Extra Transparant
- **Default Display**: Shows your custom wallpaper cleanly behind web pages while keeping inner content cards, dialogs, and text readable and solid.
- **Extra Transparant**: Optional checkbox to enable extreme glassmorphism where inner panels and cards become semi-transparent with a 5 px backdrop blur.

### 2. Website Targeting (Scope)
- **All Websites (Default)**: Wallpaper displays across all websites you visit.
- **Specific Websites**: Restrict wallpaper display exclusively to specified domains (e.g., `google.com`, `youtube.com`). Quickly add current websites with a single click.

On a fresh installation, blur starts at **0 px** and dim at **50%**. Overlay color starts on **Auto**: black for a dark device theme and white for a light device theme. The color updates if the device theme changes. Existing users keep their blur, dim, and color choices when updating.

The welcome page includes an interactive preview of blur, dim, and Auto, Black, White, or Custom overlay color. Its controls do not alter saved settings.

Some sites use closed shadow roots, canvas rendering, or browser-protected pages; those surfaces may not be customizable.

To retain your original extension logo, apply these updated files over your existing extension folder without replacing `icons/icon128.png`.
